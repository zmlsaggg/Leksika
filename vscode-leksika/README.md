# Лексика для Visual Studio Code

Подсветка файлов `.lek`: служебные формы, числительные, вызовы, блоки речи,
интерполяция и комментарии `заметка`. Это подсветка, не компилятор и не
проверка правильности программы. Расширение не запускает код и не обращается к
сети. Значительная часть внутренних `.lek` в папке `лексика/` содержит Python,
а не исходники языка: для них вручную выберите режим Python в VS Code.

```lek
заметка Суммируем числа
пусть сумма равно пяти.
прибавить два к сумме.
если сумма больше нуля то
    сказать речь Сумма: (сумма) конец речи.
конец если.
```

## Установка

В VS Code откройте палитру команд → **Extensions: Install from VSIX...** и
выберите `leksika-language-0.1.0.vsix`. Или в терминале:

```sh
code --install-extension leksika-language-0.1.0.vsix
```

`.lek` — фактическое расширение пользовательских программ проекта, `.lks` не
регистрируется. Ctrl+/ вставляет `заметка` (основной переходный исполнитель).
Лексер сначала разбирает комментарий как обычные токены, поэтому латиница и
запрещённые знаки в нём могут вызвать ошибку. В C11-компиляторе `заметка`
пока не реализована. Браузерная учебная машина
дополнительно понимает `#` и `//`; настольный исполнитель их не принимает,
поэтому Ctrl+/ не вставляет их. Многострочных комментариев и строк в кавычках
в настольной грамматике нет: строки оформляются `речь … конец речи`.
Фигурные и квадратные скобки и знаковые операторы относятся к совместимой форме
переходного исполнителя, а не ко всему нативному подмножеству. Поддержка
отступов и распознавание синтаксиса TextMate приблизительны; специальные
разговорные профили не включены автоматически. Лицензия MIT.

Грамматика генерируется из `лексика/словарь.lek` и `лексика/морфология.lek`:
`python3 vscode-leksika/scripts/generate.py` из корня репозитория.
