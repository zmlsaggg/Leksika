Локальный запуск

Редактор и учебная машина работают в этой вкладке. Сам запуск программы не отправляет исходный код на сервер и не обращается к сети. Сеть используется только по вашему действию для загрузки выбранной модели или обращения к внешнему API.

Что поддерживает эта первая браузерная версия
  • Переменные, числа, логика и речь с подстановкой значений.
  • Арифметика, сравнения, скобки и вызовы встроенных действий.
  • Условия, циклы, перебор перечней и собственные правила с возвратом.
  • Перечни в квадратных скобках и вызовы вида сказать(значение).

Это облегчённая браузерная машина для знакомства с языком, а не полная замена настольного Лексуса. Пока не поддерживаются файловая система, подключение модулей, системные команды, вся морфология, словари и часть старых падежных команд. Полный движок продолжает развиваться отдельно.

ИИ-помощник Лексики

По умолчанию включён. Локальная модель работает прямо в браузере.

Модель ещё не загружена. Загрузка начнётся после нажатия.

Можно указать ID репозитория HF. Работают модели с совместимыми ONNX-весами и архитектурами Transformers.js; не каждый репозиторий поддерживает браузерный запуск. Файлы скачиваются с Hugging Face и кэшируются браузером. WebGPU используется при наличии, иначе WebAssembly.

Код передаётся модели только после вашего запроса.

Локальная модель не отправляет код на сервер. При выборе API провайдер получит код и вопрос. Не вставляйте секреты. Загрузка требует интернета, памяти и совместимого браузера. Выключение помощника очищает API-ключ.
