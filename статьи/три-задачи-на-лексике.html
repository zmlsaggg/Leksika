Три задачи
на Лексике

Синтаксис запоминается за пять минут, а язык становится понятным только на программе, которую хочется дописать. Ниже — одна законченная программа: перечень покупок, цены в словаре, цикл с накоплением и собственное правило для вывода.

Автор: zmlsaggg · 16 ноября 2026 · Чтение: 9 минут · Русский / Практика

Задача: посчитать итог по списку покупок

Условия простые: есть перечень предметов, у каждого предмета есть цена в словаре, нужно вывести каждый предмет и общий итог. В обычном языке это три структуры данных и один цикл. В Лексике — то же самое, но команды читаются как действия.

ПРИМЕР / СКЛАД.LEK · НАСТОЛЬНЫЙ ИСПОЛНИТЕЛЬзаметка Перечни и словари, всё словами
пусть покупки равно перечень().
добавить в покупки Хлеб.
добавить в покупки Молоко.
добавить в покупки Сыр.
сказать речь В перечне (длина покупок) предметов. конец речи.

пусть цены равно словарь().
записать в цены по ключу Хлеб тридцать.
записать в цены по ключу Молоко шестьдесят.
записать в цены по ключу Сыр девяносто.
сказать речь Хлеб стоит (прочитать из цен по ключу Хлеб) рублей. конец речи.

пусть итог равно нулю.
для каждого предмета из покупок повторять
    увеличить итог на прочитать из цен по ключу (предмет).
конец для.

Этот файл лежит в репозитории как примеры/склад.lek и входит в проверки: если язык изменится так, что пример перестанет работать, сборка это покажет. Запускать его нужно настольным исполнителем — в браузерной песочнице нет ни словарей, ни падежных команд для них.

Разбор по частям

1. Перечень и добавление

пусть покупки равно перечень() заводит пустой перечень. Обратите внимание на множественное число имени: Лексика узнаёт его и в родительном — длина покупок — и в единственном числе. Движку не нужно, чтобы автор программы помнил «правильную» форму: таблица форм строится от имени автоматически.

Дальше добавить в покупки Хлеб — это винительный падеж, команда, которая по шаблону ждёт предлог в плюс винительный. Слово с заглавной буквы, которого нет среди имён, считается значением само по себе, поэтому Хлеб — это речь, а не переменная.

2. Словарь и ключи

Словарь заводится как словарь(), а запись идёт командой записать в цены по ключу Хлеб тридцать. Форма записи длиннее, чем цены["Хлеб"] = 30, и это осознанный компромисс: команда проговаривается целиком, зато не требует знать, что такое скобки конкретно в этом языке.

Чтение — прочитать из цен по ключу (предмет). Здесь в круглых скобках стоит уже не литерал, а значение переменной предмет, которое меняется на каждой итерации.

3. Цикл с накоплением

для каждого предмета из покупок повторять … конец для — перебор с локальной переменной. Внутри увеличить итог на … прибавляет к накопителю цену текущего предмета. Никаких i++ и индексов: итерация идёт по значениям, а не по позициям.

4. Речь с подстановкой

Текст открывается словом речь и закрывается конец речи. Круглые скобки внутри вставляют значение выражения: сказать речь Итого: (итог) рублей. конец речи. Точка в конце строки завершает действие.

ЧТО ЗДЕСЬ ГЛАВНОЕ

Программа не содержит ни одного оператора присваивания. Запись в перечень, запись в словарь и увеличение счётчика — три разные команды с разными падежными шаблонами, и каждая читается как предложение. Именно это Лексика и проверяет: можно ли выразить изменение данных глаголами и формами слов, не теряя однозначности.

Вторая задача: своё правило

Правило — это подпрограмма. Оно объявляется словом правило, принимает параметры и возвращает значение через вернуть.

ПРАВИЛО / СУММА ДВУХ ЧИСЕЛправило сумма(первое, второе) {
    вернуть(первое + второе);
}

пусть результат = сумма(12, 30);
сказать(речь Результат: (результат). конец речи);

Этот вариант работает в браузерной песочнице и проверяется её набором примеров. Правила собираются до исполнения, поэтому порядок объявления не важен: правило можно вызвать в тексте раньше, чем оно объявлено. Внутри правила работает своя область видимости — параметры видны только в теле, а внешние имена доступны по цепочке от ближней области к дальней.

У полного настольного исполнителя запись другая: параметры вводятся словом принимает, а блок закрывается словами конец правила. Это расхождение между учебной и полной грамматикой, а не ошибка примера — подробности в руководстве.

Третья задача: ветвление и цикл

Условия и циклы с предусловием выглядят привычно, но без английских слов:

ЦИКЛ С УСЛОВИЕМ (ПЕСОЧНИЦА)пусть счёт = 0;

пока (счёт < 5) {
    счёт++;
    сказать(счёт);
}

Фигурные скобки и знак < — это совместимая форма записи, знакомая по C-подобным языкам. В той же программе на словесной форме используется пока счёт меньше пяти повторять … конец пока, и это тоже корректная Лексика: язык принимает обе формы, но не смешивает их произвольно внутри одной конструкции. Латинские ключевые слова вроде if или while запрещены в любой форме.

Где это запускать

Один и тот же пример ведёт себя по-разному в зависимости от среды, и это важно понимать до первой ошибки:

СредаЧто сработаетЧего не будет
Песочница Переменные, число, речь, условия, циклы, перечни, правила Словари, модули, файловая система, полная морфология
Настольный исполнитель Полный язык, включая словари и падежные команды Требует установки; для Linux и macOS нужен Python 3.8+
Нативное ядро --нативно Подмножество: арифметика, условия, циклы, перечни, правила Словари, интерполяция речи, модули; имя нужно указывать точно

Что попробовать дальше

  • Заменить цены на дробные: тридцать запятая пять — дробная часть отделяется словом, а печатается через запятую.
  • Добавить предмет, которого нет в словаре, и посмотреть, как ведёт себя ошибка.
  • Перенести подсчёт итога в правило с перечнем в параметре.
  • Сравнить вывод в песочнице и в настольном исполнителе — расхождения покажут границы учебной машины.
