# leksika-git для AUR

Этот PKGBUILD собирает из `main` экспериментальный нативный C11-компилятор и
VM, а не полный настольный Python-исполнитель. Команда `leksika` — это сам
`лексус-ядро`: она принимает `выполнить файл.lek`, не общий синтаксис CLI
`Leksika`. Без Python выполняется лишь описанное в проекте подмножество языка.
Никакого fallback к Python нет.

```sh
makepkg -si
leksika --self-test
leksika выполнить /usr/share/doc/leksika-git/examples/нативная_vm.lek
leksika слово книга /usr/share/leksika/русские_формы.lxd
```

Для `слово` и `подсказки` путь к индексу нужен явно: текущий CLI иначе ищет
файл относительно рабочего каталога. Поиск по умолчанию в системной директории
ещё не реализован. Индекс также используется нативной командой `разобрать`, но
по умолчанию она ищет `ядро/русские_формы.lxd` относительно рабочего каталога
и без индекса работает без полного словаря.
Исходный словарь распространяется под отдельной MIT-лицензией, которая
устанавливается рядом с лицензией проекта.

Для сборки нужен `base-devel` и зависимости PKGBUILD. После изменения PKGBUILD
обновляйте `.SRCINFO` командой `makepkg --printsrcinfo > .SRCINFO` в Arch Linux;
для опубликованной git-версии обновите поле pkgver согласно `pkgver()`.
Сборка скачивает изменяющуюся ветку `main`; `SKIP` предусмотрен для VCS, а не
служит проверкой подлинности исходного кода. Публикация пакета не выполнялась.
