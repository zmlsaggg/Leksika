# Необязательный C++ интерфейс

`лексус.hpp` — небольшая C++17-обёртка над **тем же** C11 API компилятора и VM.
Она владеет скомпилированной программой и значениями через RAII и переводит
ошибки в `std::runtime_error`. Она не является новым компилятором, песочницей,
реализацией C++ в Лексике или заменой полного Python-исполнителя.

```cpp
#include "cpp/лексус.hpp"

ЛексусСредаИсполнения среда{}; // По умолчанию все действия запрещены.
Лексус::Программа программа("вернуть 42.");
auto результат = программа.исполнить(среда);
```

Подключайте скомпилированные **как C11**, не как C++, модули `значения.c`,
`байткод.c`, `машина.c`, `компилятор.c` и линкуйте их с кодом C++17. Пример
такой сборки и проверки: `bash cpp/проверить.sh`. Пользователю готового нативного
CLI C++ не нужен. Программа хранится только в процессе и не является стабильным
форматом байткода для обмена между версиями.

Среду с необходимыми callbacks и разрешениями надо передавать явно; нулевая
политика запрещает действия среды. Ограничение шагов задаётся отдельно (по
умолчанию миллион, ноль не принимается). Вызывающий код должен гарантировать
жизнь контекста и callbacks на время исполнения и **не должен пропускать C++
исключения через C callbacks**: перехватите их внутри и верните ошибку. VM не
является полной песочницей; встраивающее приложение отвечает за изоляцию.
Значения-контейнеры имеют общие изменяемые данные; копия обёртки копирует
ссылку, а не данные. Правила потокобезопасности у C-модулей не гарантируются.
