# Роадмап самостоятельного движка Лексики

Цель: готовый Лексус запускает Лексику без Python у пользователя. C11 остаётся только bootstrap-ступенью до самохостинга.

## Уже закрыто
- Собственные значения и точная десятичная арифметика.
- Регистровая VM, верификатор байткода и лимит шагов.
- `если/иначе`, `пока`, `повторить`, `прервать`, `продолжить`.
- Нативные перечни и обход `где` / `для каждого` с локальной переменной.
- `что`, условная форма `когда`, `почему`.
- UTF-8, числительные, базовая морфология и бинарный словарь LEKSLXD1.
- Нативный запуск без Python в PATH для поддерживаемого подмножества.
- Browser playground с отдельными режимами кода/чата и морфологическими подсказками.

## Проверенные результаты

- Linux: полный `make clean all test` и полный ASan/UBSan-прогон прошли.
- Закреплённый словарь: 1 528 715 уникальных форм из 1 532 628 строк; 41 051 188 байт; CRC32 `78EE39A5`.
- Сжатый индекс размером 6,7 MiB опубликован в `ядро/русские_формы.lxd.gz`; браузер загружает его лениво и проверяет CRC.
- Linux/macOS-установщик собирает индекс из закреплённого submodule до копирования ядра. Linux-установщик, differential-прогон и браузерная загрузка индекса прошли; macOS runtime отдельно не проверялся.
- Windows: полный `make clean all test` прошёл; для MinGW используются MSYS2 shell, ASCII-имена выходных файлов и `clock()` вместо недоступного `timespec_get`. ASan/UBSan подтверждены на Linux.

## Ближайший рывок

### 1. VM 2.0 — вызовы и настоящие области
- Кадры вызовов правил в нативной VM.
- Локальные области и параметры без Python/AST.
- `как <правило>` как настоящая инструкция `ВЫЗОВ`.
- Возврат значения из кадра и безопасная глубина стека.

### 2. Полная лексическая база
- [x] Собирать закреплённый словарь на CI и сохранять фактическую статистику.
- [x] Публиковать сжатый `ядро/русские_формы.lxd.gz` рядом с GitHub Pages.
- [x] Подключить сборку того же ресурса к Linux/macOS-установщику; Linux-пакет проверен, macOS runtime-проверка ещё нужна.
- [ ] Добавить POS/частотность/стилистику только из проверенных источников.

### 3. Естественный синтаксис
- Довести `как` и временную форму `когда ... наступит` через явную среду событий.
- Интерполяция речи.
- Падежное разрешение имён и согласование рода/числа/падежа.
- Не превращать неоднозначность в угадывание.

### 4. Стандартная среда
- Файлы через разрешаемые callbacks VM.
- Время, случайность и модули через тот же интерфейс.
- Policy enforcement внутри VM, а не только в переходном API.

### 5. Удаление переходного слоя
- Один общий differential-набор: переходный исполнитель ↔ native VM.
- Все `.lek` примеры из документации запускаются новой VM.
- Python исключается из обычного запуска и установщиков.
- После этого — самохостящийся компилятор и воспроизводимая сборка.

## Финальная цель

`Leksika программа.lek` → собственный компилятор → собственный байткод → собственная VM → собственная стандартная среда.

Python и C-компилятор не нужны пользователю.
