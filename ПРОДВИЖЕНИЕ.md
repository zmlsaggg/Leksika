# Витрина проекта: описание, темы, ключевые слова

Здесь лежат готовые тексты для настроек репозитория. Скопируйте и вставьте —
это и есть главный рычаг для выдачи: GitHub хорошо ранжирует описание, темы и
README, а поисковики читают их как обычные страницы.

## 1. Название и описание репозитория

Поле **Description** (около 150 знаков, влезает в выдачу целиком):

```
Лексика — русский язык программирования на падежах. Файлы .lek, движок Лексус, установщик для Windows. Без латиницы и зависимостей.
```

Короткий вариант, если нужно совсем сжато:

```
Лексика — язык программирования на русском языке: .lek, падежи, движок Лексус.
```

Имя репозитория лучше держать латиницей, а в описании — русские слова:
`lexica` или `lek-language`. В поле **Website** поставьте адрес страницы
(`index.html` на GitHub Pages).

**Свои имена.** Лексика, Лекс, Лексик, Лексус, лекс, LEKS, `.lek`, `lek`.

**Широкие запросы.** Русский язык программирования, язык программирования на
русском языке, программирование на русском, код на русском, писать код

## 5. Что ещё двигает выдачу

1. **GitHub Pages.** Включите в настройках, источник — ветка `main`, папка
   `/ (root)`. Тогда `index.html` открывается по адресу и индексируется
   поисковиками. Не забудьте заменить `example.github.io/lexica` в
   `sitemap.xml`, `robots.txt` и `index.html` на настоящий адрес.
2. **Релиз 1.0.0.** Приложите `Лексус-установщик.exe`. Страницы релизов
   индексируются отдельно, а «Download» на витрине заметно повышает переходы.
3. **Темы и описание — прямо сейчас.** Это первые 30 секунд работы, которые
   дают больше всего.
4. **README должен читаться сверху.** Знак, одно предложение, кнопка скачать,
   первый пример кода — всё в первом экране.
5. **Картинка для соцсетей.** Настройки → Social preview → загрузите
   `значки/Лексика.png`. Ссылка на проект начнёт разворачиваться в карточку.
6. **Русские заголовки в документации.** Поисковики ранжируют `документы/*.md`
   отдельными страницами на Pages; там уже стоят заголовки с ключевыми словами.
7. **Внешние упоминания.** Форум, Хабр, профильные чаты, ответы на вопросы
   «есть ли язык программирования на русском». Каждая внешняя ссылка на
   репозиторий усиливает его вес.
8. **Обновления.** Звёзды приходят к живым проектам: правка раз в неделю
   заметнее, чем сто правок в один день.

## 6. Чего не делать

* не набивать ключевые слова повторами в одном абзаце;
* не дублировать одно и то же описание в десяти файлах;
* не писать в описании того, чего в проекте нет;
* не покупать накрутку звёзд: GitHub это ловит, а поисковики понижают.
