# Участие в проекте «Лексика»

Лексика — русский язык программирования на движке Лексус. Правки приветствуются,
правила короткие.

## Что можно присылать

* новые слова и падежные формы в `лексика/словарь.lek` и `лексика/морфология.lek`;
* проверки в `проверка/тесты.lek` — на каждый новый случай;
* примеры программ в `примеры/` — короткие и понятные без пояснений;
* правки документации в `документы/`;
* улучшения установщиков: `установить.lek` и `сборка/установщик.c`.

## Правила кода

1. Всё по-русски: имена, сообщения, справка, ошибки. Латиница только там, где
   её требует python: имена модулей стандартной библиотеки.
2. Внешних зависимостей нет. Только python 3.8 и стандартная библиотека.
3. Расширение исходников — `.lek`. Файлы `.py` в проекте не заводятся.
4. В коде языка допустимы только знаки `. , ! ? ( )`. Ни кавычек, ни двоеточий,
   ни подчёркиваний.
5. Свой загрузчик частей — `лексика/загрузка.lek`. Сторонний механизм импорта
   не подключаем.

## Перед отправкой

```sh
python3 проверка/тесты.lek                 # ожидается 100 из 100
python3 проверка/проверить_документы.lek   # ожидается 0 ошибок
python3 лексус.lek запустить примеры/склад.lek
```

Если правка касается установщика для Windows:

```sh
sudo apt-get install mingw-w64
python3 сборка/собрать_exe.lek
```

## Как оформить

* одна правка — одна мысль;
* в описании правки скажите, что было не так и что стало;
* новые слова языка добавляйте вместе с примером и проверкой.

## Чего не делаем

* не добавляем латиницу в синтаксис языка;
* не тянем внешние пакеты и не собираем зависимости;
* не копируем строгие правила других языков: логика Лексики — падежи, а не
  порядок слов.
