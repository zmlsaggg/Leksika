# Онлайн-песочница Лексики

Адрес: https://zmlsaggg.github.io/Leksika/playground.html

Песочница позволяет попробовать учебное подмножество Лексики непосредственно
в современном браузере. Устанавливать Лексус, Python, C-компилятор или
сторонние библиотеки для этой страницы не нужно.

## Запуск программы

1. Откройте онлайн-песочницу.
2. Выберите пример или напишите программу в редакторе.
3. Нажмите «Запустить» или сочетание Ctrl + Enter.
4. Результат и ошибки появятся в панели вывода.

Исполнение идёт локально в JavaScript-машине страницы. Код не отправляется
на сервер Лексики. Учебная машина не предоставляет программе доступ к файлам,
командам операционной системы, сети или загрузке модулей.

## Поддерживаемое подмножество

На текущем этапе доступны:

- переменные и присваивания;
- числовые и логические значения, арифметика и сравнения;
- круглые скобки и вызовы функций;
- вывод и речь с подстановкой выражений;
- условия, циклы, перебор перечней;
- собственные правила с параметрами и возвратом;
- перечни и базовые встроенные действия.

Полный настольный Лексус поддерживает больше возможностей: морфологию,
падежное управление, словари, подключаемые модули, файлы, заплатки,
аудит и защищённую политику. Онлайн-песочница пока не заменяет полный движок.
Поддерживаемые конструкции и примеры будут расширяться постепенно.

## Необязательный ИИ-помощник

Функция отключена по умолчанию. Чтобы включить её, отметьте «Включить ИИ»,
укажите формат API, точный идентификатор модели, полный адрес метода,
свой API-ключ и вопрос.

Доступны три формата:

- **OpenAI-совместимый Chat Completions.** Подходит для OpenAI и провайдеров,
  которые реализуют совместимый запрос/ответ. Указывайте полный URL, включая
  `/chat/completions`. Примеры шлюзов: OpenRouter, Groq, DeepSeek, Together,
  LM Studio и другие.
- **Anthropic Messages API.** Использует собственный формат сообщений Anthropic.
- **Google Gemini API.** Использует `generateContent` и заголовок
  `x-goog-api-key`; выберите ID модели, а сегмент `MODEL_ID` в шаблоне
  адреса заменится автоматически.

Помощник отправляет запрос только после нажатия кнопки. В запрос включаются
текст вопроса и текущий исходный код. Ключ передаётся выбранному API в
заголовке, не записывается сайтом в локальное хранилище и очищается при
выключении помощника. Значения полей не сохраняются сайтом между
перезагрузками страницы.

**Перед отправкой провайдер получит текст вашего кода и вопрос.** Не
добавляйте в них пароли, закрытые исходники, секреты или персональные данные.
Запрос отправляется напрямую с браузера к провайдеру; сайт не проксирует
и не хранит API-ключ. Браузер разрешит такой запрос только если API-провайдер
допускает CORS для сайта. В противном случае потребуется официальный
browser endpoint или ваш собственный локальный шлюз.

Не все модели и серверы поддерживают один и тот же протокол. Для неподдержанного
формата используйте совместимый шлюз. Расходы, лимиты, хранение запросов и
условия обработки данных определяет провайдер, владелец API-ключа.

## Что дальше

Онлайн-песочница — отдельный ознакомительный инструмент. Основная цель
проекта остаётся прежней: довести собственный компилятор и VM Лексики до
самостоятельного исполнения без Python и без обязательного C-компилятора
на пользовательской системе.
