# Онлайн-песочница Лексики

Песочница — облегчённая учебная машина, работающая в браузере. Она не является полной заменой настольного Лексуса.

## ИИ-помощник

Помощник включён по умолчанию. Есть два источника модели:

1. **Hugging Face в браузере.** Укажите публичный ID модели и загрузите её веса напрямую в браузер. Используется Transformers.js, ONNX Runtime Web и WebGPU при наличии; при сбое WebGPU предусмотрен резервный запуск через WebAssembly. Веса кэшируются браузером.
2. **Внешний API.** Поддерживаются OpenAI-совместимый API, Anthropic и Gemini. Пользователь сам вводит адрес, модель и ключ. Код и вопрос отправляются провайдеру только после нажатия кнопки.

Можно указать произвольный ID публичного репозитория Hugging Face, но фактически запустятся только модели, у которых есть совместимые ONNX-веса и архитектура, поддерживаемая установленной версией Transformers.js. Обычные PyTorch .bin или .safetensors сами по себе не гарантируют браузерный запуск. Закрытые или gated-модели, требующие токена, не поддерживаются этим публичным загрузчиком. Первое скачивание может занимать сотни мегабайт; размер зависит от модели и квантизации. Пользователь должен проверить свободную память устройства.

## Стили ответа

- **Строгий:** только падежи, склонение, род, число и согласование. Свободные ответы и выдумывание команд отключены.
- **Баланс:** объяснение команд и неизвестных слов; догадки явно помечаются, несуществующие команды не выдаются за реальные.
- **Креатив:** свободные ответы вне кода. При обсуждении кода факты и фантазия разделяются; исходная программа не переписывается без просьбы.

Ни один стиль не меняет грамматику или правила исполнения. Ответ LLM не является авторитетным решением компилятора: синтаксис проверяет сама песочница.

## Приватность и безопасность

- Локальная модель обрабатывает вопрос и код в браузере; исходный текст не отправляется на сервер модели. Скачиваются только файлы модели и runtime.
- При использовании API выбранный провайдер получает вопрос и код.
- API-ключ не сохраняется в localStorage и очищается при выключении помощника.
- Исходный код считается данными, а не инструкциями для модели.
- Браузерная LLM не получает права исполнять команды ОС или менять код редактора.
