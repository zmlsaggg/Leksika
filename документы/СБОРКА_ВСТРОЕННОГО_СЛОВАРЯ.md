# Сборка встроенного словаря

Пользователь не запускает Python-импортёр и не скачивает словарь при работе программы.
Источник закреплён Git submodule на commit d68c007fe9260d2d40ce413f13f77335c5af1e62.

## Подготовка исходников

Для уже клонированного репозитория:

```powershell
git submodule update --init --recursive
```

## Сборка индекса

Нужен C11-компилятор (GCC или Clang) только для bootstrap-сборщика:

```powershell
make -C ядро
```

Команда создаёт ядро/русские_формы.lxd из закреплённого CP1251-источника.
Сборщик нормализует регистр, проверяет записи, сортирует и удаляет дубликаты.
Если после очистки осталось меньше 1 500 000 уникальных форм, сборка завершается ошибкой.
В конце сборки печатаются число уникальных форм, число исходных строк, число
отброшенных записей, размер готового файла, CRC32 и фактическое время построения.

Формат LEKSLXD1 содержит версию, количество форм, таблицу смещений, UTF-8-блок
и CRC32. Runtime загружает готовый read-only индекс, не разбирает исходный TXT
и не обращается к сети.

## Подключение к подсказкам

Настольная переходная диагностика лениво читает тот же LEKSLXD1 из
ядро/русские_формы.lxd: точный поиск определяет, является ли неизвестная форма
общеупотребительной, а префиксный/вариантный поиск предлагает написание.
Отсутствие файла не запрещает новые пользовательские имена и не останавливает
программу.

Браузерный редактор лениво загружает сжатый индекс по адресу
/ядро/русские_формы.lxd.gz, распаковывает LEKSLXD1 и проверяет CRC перед
включением подсказок. GitHub Actions собирает и публикует этот ресурс рядом
с GitHub Pages.

## Проверка

```powershell
make -C ядро dictionary-test
make -C ядро test
```

Команды нативного ядра:

```powershell
.\ядро\лексус-ядро.exe слово привет
.\ядро\лексус-ядро.exe подсказки прив
```

Если запускается из корня репозитория, путь к индексу по умолчанию —
ядро/русские_формы.lxd. Можно передать другой путь третьим аргументом.

## Установщик

Скрипт подготовки Windows-установщика запускает C11-сборщик автоматически
до упаковки папки ядра. Поэтому готовый бинарный индекс включается в payload
вместе с MIT notice; исходный russian.txt в пользовательский пакет не попадает.

## Проверенный результат и ограничения

Полная генерация прошла в CI на Linux и Windows: 1 528 715 уникальных форм
из 1 532 628 исходных строк; отброшено 194 записи; индекс 41 051 188 байт;
CRC32 `78EE39A5`. Сжатая версия для Pages — 6,7 MiB, SHA-256
`9a12d0960dc58653fe27721e9213e971a9002016b20d8b51be1458434615c12a`.
Linux-установщик проверен; macOS-проверка добавлена в CI.

Источник не содержит POS, частотность или надёжные стилистические метки.
Эти данные остаются отдельной задачей и не должны генерироваться догадками.
Полный перенос интерпретатора также не завершён: основной запуск .lek всё ещё
использует переходную Python-реализацию.
