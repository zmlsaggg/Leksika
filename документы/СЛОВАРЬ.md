# Словарь языка Лексика

Словарь собран из самого движка: запустите `python3 лексика/собрать_словарь.lek`, и файл обновится.

Ключевое слово узнаётся **по начальной форме**, поэтому `сказать`, `скажи`, `сказал`, `скажет` — одно слово языка. Обычные имена движок склоняет сам, и они узнаются в любом падеже: `сумма`, `суммы`, `сумме`, `сумму`, `суммой`.

## Объявление и присваивание

| слово | узнаётся как | что значит |
|---|---|---|

| **равно** | означает, равен, равна, равно, равны, равняется | связка имени и значения, а также сравнение «равно» |
| **положить** | кладу, кладём, кладёт, класть, положи, положит, положить … | положить значение во имя: «положить пять в сумму» |
| **увеличить** | нарасти, нарастить, увеличивает, увеличить, увеличь | прибавить к имени: «увеличить счёт на два» |
| **уменьшить** | срежь, срезать, уменьшает, уменьши, уменьшить | отнять от имени: «уменьшить счёт на два» |
| **прибавить** | дополни, дополнить, прибавить, прибавляет, прибавь | прибавить к имени, дополнение в дательном падеже |
| **отнять** | вычесть, вычти, отнимает, отними, отнять | отнять от имени, дополнение в родительном падеже |

## Встроенные команды с падежным управлением

Команда сама указывает, в каком падеже стоит имя.

| команда | образец | что делает |
|---|---|---|
| **взять** | `пусть первый равно взять из перечня ноль.` | Берёт элемент перечня по номеру. Нумерация с нуля. |
| **длина** | `если длина перечня больше трёх то ... конец если.` | Длина речи или перечня. Имя ставится в родительный падеж. |
| **добавить** | `добавить в покупки молоко.` | Добавляет значение в конец перечня. |
| **записать** | `записать в цены по ключу хлеб сорок.` | Пишет значение в словарь по ключу. |
| **прочитать** | `пусть цена равно прочитать из цен по ключу хлеб.` | Читает значение из словаря по ключу. |
| **убрать** | `убрать из покупок ноль.` | Убирает элемент перечня по номеру. |

## Встроенные функции

Функции узнаются по скобке после слова, поэтому имя переменной может совпадать с их именем.

| запись | что делает |
|---|---|
| `буквы(речь)` | Разбивает речь на отдельные буквы. |
| `время()` | Текущее время в виде речи. |
| `ключи(словарь)` | Перечень всех ключей словаря. |
| `корень(значение)` | Квадратный корень числа. |
| `модуль(значение)` | Модуль числа, то есть значение без знака. |
| `молча(значение)` | Возвращает значение, ничего не делая — для отладки. |
| `округлить(значение)` | Округляет дробное число до целого. |
| `остаток(делимое, делитель)` | Остаток от деления одного числа на другое. |
| `перечень()` | Создаёт перечень. Пустые скобки — пустой перечень. |
| `словарь()` | Создаёт пустой словарь (толкователь). |
| `случайное(от, до)` | Случайное целое число в указанных пределах. |
| `строка(значение)` | Превращает число или иное значение в речь. |
| `целое(значение)` | Отбрасывает дробную часть числа. |
| `число(значение)` | Превращает речь в число. |

## Необязательные разговорные профили

Разговорные синонимы не входят в базовый словарь. Они подключаются только
переключателями и по умолчанию выключены:

```sh
лексус настройка взрослая_лексика да
лексус настройка зумер_лексика да
лексус настройки
```

Профиль **18+** добавляет грубые варианты команд: `пиздануть` (`сказать`),
`въебать` (`увеличить`), `нахерачить` (`положить`), `разъебать`
(`убрать`) и другие. Для имён и речевых значений доступны также `пиздец`,
`хуйня`, `говно`, `жопа`, `дерьмо`, `пиздёж`, `заёб`, `мудак`, `еблан`,
`мудила`, `блядь`, `ебать`, `охуеть`, `охуенно`, `заебись`, `пиздато`,
`хуёво`, `нахуй` и `нихуя`.

Профиль **Зумер-лексика** содержит переменные-слова и их морфологические
сведения: `вайб`, `кринж`, `краш`, `рофл`, `имба`, `чил`, `тильт`,
`апрув`, `душнила`, `токсик`, `жиза`, `база`, `сигма`, `скуф`,
`пикми`, `редфлаг`, `дрип`, `трэш`, `нормис`, `чел`, `альтушка`,
`масик`, `тюбик`, `пруф`, `муд`, `слоп`, `брейнрот`, `пупупу`, а также глагольные имена `флексить`, `заскамить`, `чилить`, `тильтовать`, `тильтануть`, `апрувнуть`, `апрувить`, `душнить` и `токсичить`.
Слова по-прежнему объявляются как переменные через `пусть`; профиль задаёт
им правильный род, одушевлённость и склонение. Команда `лексус словарь`
показывает список включённых слов.

Подборка пополняется вручную: молодёжный сленг меняется быстро, поэтому
список не считается исчерпывающим. Эти профили подключены к совместимому
настольному исполнителю; нативная VM пока не читает их настройки.
