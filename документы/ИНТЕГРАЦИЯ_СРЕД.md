# Внешние среды и переход к нативному движку

Лексика имеет собственный синтаксис и байткод. Перенос полезной команды из
переходного исполнителя означает отдельно реализовать её смысл в нативном
компиляторе и VM, проверить типы, ошибки и результат на общем подмножестве.
Переименование Python-файла в `.lek` не делает его программой Лексики. Полный
настольный исполнитель всё ещё использует Python; переход отслеживается в
[плане](../ПЛАН_ПЕРЕНОСА_РАНТАЙМА.md).

## JavaScript сейчас

`node инструменты/узел.cjs запустить файл.js [аргументы...]` — отдельный,
явный запуск установленного пользователем Node.js. У Node обычные правила
поиска модулей, поэтому файл может использовать npm-пакеты, которые пользователь
уже установил в своём проекте. Адаптер не запускает npm, не скачивает пакеты,
не интерпретирует JavaScript и не подключён к `.lek` или C VM. Передача идёт
напрямую в процесс без оболочки, имена и аргументы не вычисляются как команды.

Это **не песочница**: запущенный скрипт наследует права, окружение и рабочий
каталог пользователя и может обращаться к сети и файлам. Настройки защищённого
режима Лексики к этому процессу не применяются. Разрешайте запуск только коду,
которому доверяете. Проверка: `node проверка/узел.cjs`.

## Что ещё предстоит

1. Расширять нативные команды и сопоставительные тесты с переходным runtime,
   не переключая выполнение на Python при ошибке.
2. Спроектировать явную границу интеграций: форматы данных, диагностику,
   версии протокола, ограничения ресурсов и отказ по умолчанию. До появления
   работающего механизма разрешений и изоляции не запускать сторонний код из VM.
3. Отдельно исследовать взаимодействие с внешними Python, Node.js и JVM, не
   обещая совместимость со всеми пакетами. В частности, бинарные расширения,
   зависимости ОС и поведение пакетных менеджеров требуют соответствующей
   среды и не могут автоматически превратиться в код Лексики.

Встроенный C-код не загружает и не исполняет Python, npm или Java-пакеты.
Сами сторонние среды, их зависимости и лицензии в нативный дистрибутив не
включены. Совместимость и безопасный обмен данными с `.lek` пока не реализованы.
