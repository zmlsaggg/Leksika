# Совместимая форма синтаксиса Лексики

Лексика остаётся самостоятельным русскоязычным языком. Совместимая форма
позволяет записывать знакомые структуры в стиле Python и семейства C,
не переходя на английские ключевые слова и не вводя иностранные
идентификаторы.

Это слой нормализации: он преобразует знакомую пунктуацию и структуру
блоков в существующую русскую грамматику Лексики. Исполнение по-прежнему
происходит через обычные дерево смысла, байткод и машину Лексуса.

## Два равноправных стиля

Словесный стиль остаётся неизменным и поддерживается:

```text
пусть счёт равно нулю.
пока счёт меньше трёх повторять
    увеличить счёт на один.
    сказать речь Шаг (счёт) конец речи.
конец пока.
```

В совместимом стиле ту же логику можно записать привычнее:

```text
пусть счёт = 0;
пока (счёт < 3) {
    увеличить счёт на 1;
    сказать(счёт);
}
```

Допускается и форма блоков по отступам:

```text
пусть счёт = 0
пока (счёт < 3):
    увеличить счёт на 1
    сказать(счёт)
```

## Круглые скобки

`()` — полноценная часть синтаксиса:

```text
сказать((2 + 3) * 4);
сказать(длина(перечень(хлеб, молоко)));
```

Скобки можно использовать для группировки выражений, передачи аргументов
и вызова команд. Сохраняется и прежняя запись без скобок:

```text
сказать сумма.
сказать(сумма);
```

## Операторы

Совместимый слой переводит базовые математические и логические знаки
в словесные операции Лексики:

| запись | русская операция |
|---|---|
| `=`, `==` | `равно` |
| `!=` | `не равно` |
| `>`, `<` | `больше`, `меньше` |
| `>=`, `<=` | `не меньше`, `не больше` |
| `+`, `-` | `плюс`, `минус` |
| `*`, `/`, `%` | умножение, деление, остаток |
| `**` | `в степени` |
| `&&`, `||` | `и`, `или` |

Для изменения переменной также доступны `счёт += 2`, `счёт -= 1`,
`счёт *= 3`, `счёт /= 2`, а также `счёт++` и `счёт--`. Они
преобразуются в русские действия `увеличить`, `уменьшить`,
`умножить` и `разделить`.

Для вычитания рекомендуется отделять минус пробелами, чтобы не смешивать
его с дефисом внутри составного русского имени.

## Перечни и правила

Квадратная запись перечня преобразуется во встроенный русский перечень:

```text
пусть покупки = [хлеб, молоко, сыр];
```

Доступ к элементу по индексу через квадратные скобки пока не реализован.
Используйте существующую команду `взять из перечня`.

Русское правило можно записать с привычными скобками параметров:

```text
правило сумма(первое, второе) {
    вернуть(первое + второе);
}

сказать(сумма(2, 3));
```

Поддерживается и запись с русским типом результата и типами параметров:

```text
целое сумма(целое первое, целое второе) {
    вернуть(первое + второе);
}
```

Типы в этом заголовке пока служат читаемыми аннотациями. Полноценная
статическая система типов — отдельный этап разработки.

## Условия, циклы и перебор

```text
если (счёт >= 10) {
    сказать(речь Десять или больше конец речи);
} иначе {
    сказать(речь Меньше десяти конец речи);
}

для каждого предмет в покупки:
    сказать(предмет)
```

Поддерживаемые формы блоков:

- `если (...):` или `если (...) {` — условие;
- `иначе:` или `} иначе {` — альтернативная ветвь;
- `пока (...):` или `пока (...) {` — цикл;
- `для каждого имя в перечень:` — перебор;
- `правило имя(параметры):` или `правило имя(параметры) {` — правило.

В отступном стиле уровень отступа определяет конец блока. В фигурном стиле
каждый открытый блок должен иметь закрывающую `}`. Для переносимости
рекомендуется ставить одну закрывающую скобку на отдельной строке.

## Что не означает совместимость

Совместимость относится к базовым структурным соглашениям, а не к полным
грамматикам других языков. На этом этапе не поддерживаются:

- английские ключевые слова Python, C++, Java и других языков;
- латинские имена переменных и функций;
- классы, шаблоны, указатели, лямбда-выражения и пространства имён C++;
- декораторы, генераторы и полная семантика Python;
- индексирование `список[номер]`, срезы и словари в фигурных скобках;
- произвольные конструкции, специфичные для стороннего языка.

То есть это не универсальный конвертер исходников и не обещание, что
произвольный файл Python или C++ можно просто переименовать в `.lek`.
Цель — дать разработчику привычную форму записи, сохранив русскую лексику,
русские имена и собственную семантику Лексики.

В дальнейшем новые формы можно добавлять отдельными адаптерами синтаксиса,
которые переводят конструкции в общее дерево Лексики. Это позволит развивать
совместимость постепенно, не превращая ядро языка в набор несвязанных
грамматик.
