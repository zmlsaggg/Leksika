# Лексика — язык программирования на русском

**Лексика** — экспериментальный язык программирования, у которого команды,
имена и связи слов построены вокруг русской грамматики. Падеж слова помогает
понять его роль в операции. Программы хранятся в файлах `.lek`.

Этот пакет — **переходный исполнитель на Python 3.8+** (движок «Лексус»).
Нативное ядро на C11 развивается отдельно и пока исполняет только подмножество
языка; полный переход на него не завершён. Пакет не заменяет установщик для
Windows, Android APK и нативные архивы из релизов.

## Установка через pip

Требуется Python 3.8 или новее. Имя пакета в PyPI — `leksika`.

**Windows (PowerShell):**

```powershell
py -m pip install --upgrade leksika
leksika справка
```

**Linux и macOS:**

```sh
python3 -m pip install --upgrade leksika
leksika справка
```

При необходимости установи пакет в отдельное виртуальное окружение:

```powershell
# Windows
py -m venv .venv
.venv\Scripts\Activate.ps1
```

```sh
# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate
```

После активации окружения:

```sh
python -m pip install --upgrade leksika
leksika справка
leksika запустить пример.lek
```

Если команда `leksika` не находится, запусти её через модуль: `py -m leksika_engine справка` в Windows или `python3 -m leksika_engine справка` в Linux/macOS. Команда `leksika где` показывает местоположение движка и каталога скриптов.

Вместе с `leksika` устанавливаются псевдонимы `leksus` и `lek`. Исходники движка (`.lek`) лежат внутри пакета, отдельный репозиторий не нужен. Настройки и заплатки хранятся в `~/.lek`, а не в каталоге пакета.

В пакет входит переходный исполнитель целиком: части на `.lek`, примеры, программы, словари, документы и данные словаря. В нём нет готовых бинарников экспериментального нативного ядра и браузерной песочницы.

Обновить: `python -m pip install --upgrade leksika`. Удалить: `python -m pip uninstall leksika`.

### Если команда `leksika` не находится

`pip` ставит её в каталог скриптов Python, который в Windows часто не входит в
`PATH`. Запуск через `-m` работает без `PATH` всегда:

```text
py -m leksika_engine справка     # та же справка
py -m leksika_engine где         # куда всё поставилось и где искать команду
```

`Leksika где` печатает движок, примеры, словари, версию Python, каталог пакета
и точный путь каталога скриптов, который нужно добавить в `PATH`.

## Пример

```text
пусть сумма равно пяти.
положить десять в сумму.
прибавить два к сумме.
сказать речь Сумма равна (сумма) конец речи.
```

Вывод: `Сумма равна 12`.
