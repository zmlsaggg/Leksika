# Лексика — язык программирования на русском

**Лексика** — экспериментальный язык программирования, у которого команды,
имена и связи слов построены вокруг русской грамматики. Падеж слова помогает
понять его роль в операции. Программы хранятся в файлах `.lek`.

Этот пакет — **переходный исполнитель на Python 3.8+** (движок «Лексус»).
Нативное ядро на C11 развивается отдельно и пока исполняет только подмножество
языка; полный переход на него не завершён. Пакет не заменяет установщик для
Windows, Android APK и нативные архивы из релизов.

## Установка и запуск

```sh
python -m pip install --upgrade leksika
leksika справка
leksika запустить пример.lek
```

Вместе с `leksika` ставятся псевдонимы `leksus` и `lek`. Исходники движка
(`.lek`) лежат внутри пакета, отдельный репозиторий не нужен. Настройки и
заплатки хранятся в `~/.lek`, а не в каталоге пакета.

В пакете весь движок, а не только запускатор: части на `.lek`, примеры,
программы, словари, документы и данные словаря. Нет только готовых бинарников
нативного ядра (они в архивах релизов под каждую платформу) и браузерной
песочницы.

### Если команда `leksika` не находится

`pip` ставит её в каталог скриптов Python, который в Windows часто не входит в
`PATH`. Запуск через `-m` работает без `PATH` всегда:

```text
py -m leksika_engine справка     # та же справка
py -m leksika_engine где         # куда всё поставилось и где искать команду
```

`Leksika где` печатает движок, примеры, словари, версию Python, каталог пакета
и точный путь каталога скриптов, который нужно добавить в `PATH`.

## Пример

```text
пусть сумма равно пяти.
положить десять в сумму.
прибавить два к сумме.
сказать речь Сумма равна (сумма) конец речи.
```

Вывод: `Сумма равна 12`.
