Leksika native bootstrap / Лексус — нативное загрузочное ядро

Это экспериментальное C11-ядро, не полный совместимый исполнитель Лексики и не
Windows-установщик. Оно выполняет только поддерживаемое подмножество .lek без
Python; остальные конструкции не переключаются автоматически на Python.
Описание: https://github.com/zmlsaggg/Leksika/blob/main/документы/ПЕРВЫЙ_НАТИВНЫЙ_КОМПИЛЯТОР.md

Примеры (на Windows используйте leksus-core.exe):
  ./leksus-core самопроверка
  ./leksus-core выполнить example.lek
  ./leksus-core слово книга dictionary.lxd

Для команд «слово» и «подсказки» указывайте полный путь к dictionary.lxd,
если запускаете из другой директории. Команда «разобрать» по умолчанию ищет
ядро/русские_формы.lxd относительно текущей директории и без него работает
без полного словаря. Индекс создан из MIT-словаря Danakt Frost; см.
DICTIONARY-LICENSE.txt. В Linux бинарник требует совместимую glibc; Android —
64-битная ARM-система и Android 7.0 (API 24) или новее. Termux не обязателен,
но может использоваться для запуска. Android-сборка не заменяет APK.
