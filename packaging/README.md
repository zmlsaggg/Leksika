# Пакеты нативного ядра

Шаблоны `homebrew/leksus-core.rb` и `scoop/leksus-core.json` в этом каталоге —
только заготовки для генератора: `0.0.0` и нулевые SHA-256 здесь **заглушки**.
Живые манифесты лежат во внешних репозиториях `zmlsaggg/homebrew-leksika`
(`Formula/leksika.rb`) и `zmlsaggg/scoop-leksika` (`bucket/leksika.json`), и
обновляются автоматически при выпуске версии — см. ниже.

Шаблоны описывают **экспериментальное подмножество** `leksus-core`, а не полный
Лексус и не существующий установщик Windows. Scoop — только Windows x64;
Homebrew — macOS ARM/Intel и Linux x64.
Словарь установлен рядом с пакетом: Scoop хранит его в каталоге версии пакета,
Homebrew — в `pkgshare`; для `слово`/`подсказки` передайте его путь явно.

## Автоматическое обновление при выпуске

Задание `update-package-managers` в `.github/workflows/release.yml` запускается
по тегу `vX.Y.Z` после успешного `publish-versioned` и обновляет оба внешних
репозитория напрямую в `main`. Оно берёт SHA-256 из опубликованного
`zz-SHA256SUMS.txt`, сверяет его с локальным артефактом, скачивает файлы из
релиза и только потом пишет:

```sh
python3 packaging/update_package_managers.py "$VERSION" \
  --sums release/zz-SHA256SUMS.txt --homebrew tap --scoop scoop-repo --verbose
```

Формула и манифест правятся точечно: меняются `version`, `url` и `sha256`/`hash`,
остальной текст, комментарии и порядок ключей сохраняются. Суммы проверяют
целостность, а не подлинность: источник релиза надо проверять отдельно.
Предварительные версии (`-alpha`, `-beta`, `-rc`) в tap и bucket не попадают.
Токен `CROSS_REPO_TOKEN` и его права описаны в `RELEASING.md`.

Проверка скрипта без сети и секретов: `python3 проверка/менеджеры_пакетов.py`.

## Ручная сборка шаблонов

Если нужно получить манифесты вручную (например, для отдельного bucket или
проверки до выпуска):

```sh
python3 packaging/update_templates.py 1.2.3 zz-checksums.txt готовые-манифесты
```

Перенесите `leksus-core.json` в `bucket/` нужного Scoop bucket и
`leksus-core.rb` в `Formula/` Homebrew tap. Проверьте установку и тесты Scoop и
Homebrew на соответствующих ОС. Генератор принимает только стабильные версии:
для предварительных нужны ручные изменения. Никогда не записывайте токен в
исходники.

`packaging/update-repository.sh` — старый сценарий с созданием PR; в
автоматическом выпуске он больше не используется.
