# Пакеты нативного ядра

Шаблоны предназначены для **экспериментального подмножества** `leksus-core`,
а не для полного Лексуса и не для существующего установщика Windows. Пока нет
версионного релиза, `0.0.0` и нулевые SHA-256 — **заглушки**: установка из
шаблонов не заработает до заполнения. Никакие bucket/tap автоматически не
публикуются. Scoop — только Windows x64; Homebrew — macOS ARM/Intel и Linux x64.
Словарь установлен рядом с пакетом: Scoop хранит его в каталоге версии пакета,
Homebrew — в `pkgshare`; для `слово`/`подсказки` передайте его путь явно.

После выпуска стабильного `vX.Y.Z` скачайте `checksums.txt` и все необходимые
архивы, проверьте их по SHA-256, затем сформируйте реальные манифесты:

```sh
python3 packaging/update_templates.py 1.2.3 checksums.txt готовые-манифесты
```

Перенесите `leksus-core.json` в `bucket/` отдельного Scoop bucket и
`leksus-core.rb` в `Formula/` Homebrew tap. Проверьте установку и тесты Scoop и
Homebrew на соответствующих ОС. Суммы проверяют целостность, не подлинность;
проверяйте источник релиза. Для тестирования предварительных версий нужны
ручные изменения: генератор и автоматические обновления допускают только
стабильные версии.

В конце `release.yml` есть выключенные jobs для создания PR в будущих внешних
репозиториях. Создайте эти репозитории с default branch, настройте имена в jobs,
создайте в настройках основного репозитория секрет `GH_PAT`: fine-grained token
с `Contents` и `Pull requests` read/write только для двух новых репозиториев.
Включите блоки; скрипт скачает и проверит каждый используемый архив, заполнит
шаблоны и создаст PR. Для повторного запуска уже существующую ветку/PR надо
разрешить вручную. Никогда не записывайте токен в исходники.
