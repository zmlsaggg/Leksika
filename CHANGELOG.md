# История изменений

Изменения проекта документируются по мере подготовки заметных обновлений.

Формат разделов основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Номера версий следуют Semantic Versioning, когда проект начнёт выпускать формальные версии.

## [Unreleased]

### Добавлено
- Основная команда запуска `Leksika` для Windows, Linux и macOS; старое имя `лексус` сохранено как совместимый псевдоним.
- Документы о безопасности, поддержке и правилах сообщества.
- Метаданные цитирования проекта.

### Изменено
- Установщики создают launcher `Leksika`; Windows добавляет каталог программы в пользовательский `PATH`, Linux/macOS устанавливают команду в `~/.local/bin`.
- Улучшена навигация README и удалён искусственный перечень поисковых фраз.
- Уточнено позиционирование проекта и статус незавершённых компонентов.

### Примечания
- `Leksika` пока скрывает запуск переходного Python-исполнителя; нативная VM без Python остаётся отдельной незавершённой задачей.
- Формальные релизы и политика поддержки версий будут объявлены отдельно.
