# История изменений

Изменения проекта документируются по мере подготовки заметных обновлений.

Формат разделов основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Номера версий следуют Semantic Versioning, когда проект начнёт выпускать формальные версии.

## [Unreleased]

### Добавлено
- Падежный ввод имён в нативном компиляторе: `сказать суммой`, `длина покупок`,
  `добавить в покупку` работают по тем же правилам склонения, что и
  `лексика/морфология.lek`; диагностика неизвестного имени перечисляет
  заведённые имена, а склонение кэшируется на имя.
- Отдельная проверка `make -C ядро morphology-test` и падежные случаи в
  `компилятор-тест` / `контракт-тест`.
- Страницы «О проекте» и «Контакты»: автор проекта, каналы связи и таблица честного статуса компонентов.
- Раздел «Статьи» с шестью материалами о падежах, переносе движка, границах песочницы, примерах программ и контексте русских языков программирования.
- Сквозная разметка Schema.org: `Organization` с `founder` и `contactPoint` на всех страницах, `AboutPage`, `ContactPage`, `Article` и `FAQPage` на главной.
- Проверка `проверка/сайт_контакты.cjs`: контакты, автор, JSON-LD, карта сайта и внутренние ссылки проверяются в CI.
- Основная команда запуска `Leksika` для Windows, Linux и macOS; старое имя `лексус` сохранено как совместимый псевдоним.
- Документы о безопасности, поддержке и правилах сообщества.
- Метаданные цитирования проекта.

### Изменено
- `Leksika` и `Leksika справка` никогда не показывают английских команд;
  `версия` и `справка` стали делами, английские флаги принимаются скрыто.
  Новая проверка `проверка/русский_cli.py` следит за обоими обещаниями.
- `make -C ядро core` собирает только ядро; цель `native` ей синонимична,
  внешний словарь подсказок остаётся необязательным (`make all`).
- `проверка/проверить_документы.lek` проверяет примеры во всех разговорных
  профилях: профильные куски больше не отбрасываются, а отчёт честно называет
  их число (сейчас 20 кусков, 0 ошибок, 2 только в профиле).
- Установщики создают launcher `Leksika`; Windows добавляет каталог программы в пользовательский `PATH`, Linux/macOS устанавливают команду в `~/.local/bin`.
- Улучшена навигация README и удалён искусственный перечень поисковых фраз.
- Уточнено позиционирование проекта и статус незавершённых компонентов.

### Примечания
- `Leksika` пока скрывает запуск переходного Python-исполнителя; нативная VM без Python остаётся отдельной незавершённой задачей.
- Формальные релизы и политика поддержки версий будут объявлены отдельно.
